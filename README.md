# Yoseph Ayalew — Professional Portfolio

A high-performance, developer-focused portfolio built with **Next.js 14**, **Tailwind CSS**, and an eye-friendly **Forest Green** design system.

## Key Features

1. **Company Enterprise Work at eTech SC**:
   - **eHealth Systems**: Chilalo Shed, Nubira, Meqrez Hospital (Java Vert.x, Angular, PostgreSQL).
   - **SACCO Financial Cooperatives**: Ethio-Trit SACCO, Netsebirak SACCO, Oromia Bank SACCO.
   - Categorized filters with client logos.
2. **Live Connected Git Activity ("Push to Portfolio")**:
   - Integrates with GitHub REST API (`Solohater`).
   - Automatically surfaces your latest commit message, target repository, and relative timestamp.
3. **Personal Full-Stack Projects**:
   - Document Manager, TechShop, Ethio Kemem Food Menu, JODEV Blog, Repair Management, Reminder App.
   - One-click copy for demo logins (`admin / admin123`).
4. **Interactive Architecture Snippet**:
   - Tabbed code preview comparing reactive Java / Vert.x endpoints with Next.js server actions.
5. **Ergonomic Eye-Friendly Palette**:
   - **Dark Mode**: Midnight Slate canvas (`#0B0F17`) with rich forest green accents (`#065F46`, `#10B981`) and off-white text.
   - **Light Mode**: Warm neutral paper canvas (`#F8FAFC`) with deep pine text and subtle borders.
   - Seamless one-click Sun/Moon toggle with system preference fallback (`prefers-color-scheme`).
6. **Command Palette (`⌘K` / `Ctrl+K`)**:
   - Instant keyboard navigation across sections, resume download, and email actions.
7. **Formspree Contact Integration**:
   - Instant feedback state without full-page reloads.

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Start production server
npm start
```
